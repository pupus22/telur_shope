# Shopee Payout Web v1.8.1

## Perubahan v1.8.1
- Editor **Edit Data Pesanan tetap berupa popup/modal**, bukan halaman penuh.
- Popup dibuat hampir memenuhi layar (sekitar 96% lebar dan 94% tinggi pada desktop).
- Background halaman tetap terlihat gelap melalui backdrop modal.
- Header popup dan tombol aksi bawah tetap terlihat ketika isi popup di-scroll.
- Pada HP popup tetap menyisakan sedikit jarak dari tepi layar dan field berubah menjadi satu kolom.
- Halaman **Siap Dicairkan** tetap memakai **Tanggal Order** sebagai filter periode.

## Deploy GitHub Pages
Ganti `index.html`, `app.js`, dan `styles.css` bersamaan, lalu lakukan `Ctrl+F5`.

Database masih menggunakan IndexedDB browser untuk tahap uji coba.
